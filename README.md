# Repacker 2.1

GR Studios AI Repacker is a Windows toolkit for compressing files, creating installers, and packaging games, software, music, and movies for distribution.

## What’s included

| Component | What it does |
| --- | --- |
| **GR Studios AI Compressor** | Compress files with FreeArc presets and verify the finished archive. |
| **Inno Setup scripts** | Create offline installers with bundled files or online installers that download files during setup. |
| **Custom game launcher** | Give packaged games a branded launch screen. |
| **GR Catgirl Player** | Play music and videos from mixed playlists, with fullscreen video, shuffle, repeat, an equalizer, and audio visualizers. |

## Getting started

Use the compressor to prepare and verify your archive. Choose an offline or online installer based on how you want to deliver the files. Use the custom launcher for games or GR Catgirl Player for music and video collections.
