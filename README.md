# Repacker 2.1

GR Studios AI Repacker is a Windows toolkit for compressing files and packaging games, software, music, and movies for distribution.

## What's included

| Component | What it does |
| --- | --- |
| **GR Studios AI Compressor** | Compress files using FreeArc presets and verify the finished archive. |
| **Offline Inno Setup scripts** | Package files for installation without an internet connection. |
| **Custom game launcher** | Give packaged games a branded launch screen. |
| **GR Catgirl Player** | Play music and videos with mixed playlists, fullscreen playback, shuffle, repeat, an equalizer, and audio visualizers. |
